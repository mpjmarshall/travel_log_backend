# Triage labels

**There are none, and that is not an omission to fix.**

`gh label list` returns GitHub's stock defaults — `bug`, `enhancement`,
`good first issue` and the rest — and not one of them has ever been applied,
because this repository has never opened an issue. See `issue-tracker.md`:
the tracker is `TODO.md`.

If a skill asks for a triage role, the nearest true equivalent is the entry's
own **tier**, which says what kind of evidence would close it:

| role a skill may ask for | what this repo has instead |
|---|---|
| `needs-triage` | an open box with no tier stated yet |
| `needs-info` | an open box whose body names the measurement nobody has taken |
| `ready-for-agent` | tier a or b — something in the repository can run it |
| `ready-for-human` | tier c — *guarded by nothing but a human with a device* |
| `wontfix` | a closed entry recorded as **declined**, with its reasoning kept |

Do not create labels to match the table on the left. The mapping exists so a
skill can be answered honestly, not so the vocabulary can be imported.
